# TimeTodo25_API

| 커밋 구분	  | 설명                  |
|---------|---------------------|
| Feat	   | 기능 구현 및 추가 개선       |
| Update	 | 기능 수정 (소소한 변경)      |
| Fix	    | 버그 수정               |
| Build	  | 빌드 프로세스 관련 수정(yml)  |
| Refactor	 | 코드 정리/리팩토링 (기능 수정X) |
| Merge	  | 머지/충돌 정리            |
| Comment	 | 주석 수정 및 추가 (코드 수정X) |
| Docs	   | 코드 외 문서 작업          |
| Test	   | 테스트 추가/수정           |

ex/ `Feat: 알 수 없는 api 추가 및 미지의 기능 구현 #연관이슈(옵션)`
